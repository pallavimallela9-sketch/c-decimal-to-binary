# Decimal to Binary

This program converts a decimal number into its binary equivalent.

## Features

* Takes a decimal number from the user
* Converts the number into binary
* Uses an array to store binary digits
* Displays the binary result

## Technology Used

* C

## Concepts Used

* Arrays
* While loop
* For loop
* Modulus operator
* Integer division

## Sample Output

```text
Enter a decimal number: 25
Binary: 11001
```
